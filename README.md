# rb-g-2026

## หิมพานต์ ออนไลน์ (Himmapan Online)

MMORPG แนวพิกเซลบนเว็บ ในป่าหิมพานต์ เขียนเป็นไฟล์เดียว: [`himmapan/index.html`](himmapan/index.html)

- มุมมองแบบ isometric สไตล์ MMORPG 2D คลาสสิก โลกขนาด 96×72 ช่อง สร้างจาก seed เดียวกัน ทุกคนจึงเห็นแผนที่เหมือนกัน
- เมืองตลาดมีวัดทอง น้ำพุกินรี (ยืนใกล้ๆ จะฟื้น HP) แผงลอย พ่อค้าแม่ค้าบนเสื่อ ผู้เฒ่าทองดี (ให้ภารกิจ) และป้าจันทร์ (ขายยาและดาบ)
- ศัตรู 4 ชนิด ยิ่งห่างหมู่บ้านยิ่งเก่ง: วุ้นป่า → เห็ดพิษ → หมูป่าหิน → นาคน้อย
- มีเลเวล XP ทอง ยาสมุนไพร อัปเกรดดาบ 4 ระดับ และภารกิจต่อเนื่อง
- เล่นบนมือถือได้ (จอยสติ๊กและปุ่มบนจอ) และบนคอม (WASD, Space, E, Q, Enter)
- ผู้เล่นหลายคน: เมื่อเปิดเป็น Claude Artifact จะเห็นกันแบบเรียลไทม์และแชทกันได้ ผ่านความสามารถ `room`
  ตัวละครถูกเซฟผ่าน `db` และสำรองไว้ใน localStorage ด้วย

### ข้อจำกัดตอนนี้
- มอนสเตอร์ยังจำลองแยกบนเครื่องของแต่ละคน (ยังไม่มีเซิร์ฟเวอร์กลาง) คนอื่นจึงเห็นกันและแชทกันได้ แต่ยังไม่ได้ตีตัวเดียวกัน
- ขั้นต่อไป: ทำเซิร์ฟเวอร์ Node.js + WebSocket ให้เป็นตัวตัดสิน (authoritative) เรื่องมอนสเตอร์ ดรอปของ และการเซฟ

### รันบนเครื่อง
เปิดไฟล์ `himmapan/index.html` ในเบราว์เซอร์ได้เลย ถ้าเปิดแบบนี้จะเล่นได้คนเดียว (ออฟไลน์)

## ไข่ปุ๊กปิ๊ก (Pukpik Egg)

RPG ฟักไข่แบบเทิร์นเบส เล่นบนเว็บ ทำมาให้เล่นบนมือถือเป็นหลัก เขียนเป็นไฟล์เดียว: [`pukpik/index.html`](pukpik/index.html)

- เข้าเกมมาจะเจอไข่ที่ค่อยๆ ร้าวและฟักเอง (แตะรัวๆ ให้ฟักเร็วขึ้นได้) ตัวที่ได้เป็นก้อนกลมๆ สุ่ม 1 ใน 5 สี มีโอกาส 5% ได้ตัว “ประกายแสง” ค่าพลังสูงกว่าปกติ
- แต่ละสีมีค่าพลังเด่นและสกิลของตัวเอง ค่าเด่นโตเร็วเป็น 2 เท่าทุกเลเวล

| สี | ชื่อ | ค่าเด่น | สกิล |
|---|---|---|---|
| แดง | ปุ๊กเพลิง | โจมตี (ATK) | หมัดเพลิง: ต่อยแรง ×2.2 |
| น้ำเงิน | ปุ๊กวารี | ป้องกัน (DEF) | โล่วารี: โจมตีแล้วกันดาเมจ 60% อีก 3 ครั้ง |
| เหลือง | ปุ๊กสายฟ้า | ความเร็ว (SPD) | สายฟ้าแลบ: ฟาด 2 ครั้ง ไม่พลาด |
| น้ำตาล | ปุ๊กผืนดิน | พลังชีวิต (HP) | ดินฟื้นฟู: ฟื้น HP 40% |
| เขียว | ปุ๊กใบไม้ | โชค (LUK) | ใบไม้ดูดพลัง: โจมตี ×1.3 คริติคอลง่าย ดูดเลือด |

- ต่อสู้แบบเทิร์น: โจมตี / สกิล / ป้องกัน / ไอเทม / หนี ใครความเร็วสูงกว่าได้ลงมือก่อน บอสจะรวบรวมพลังก่อนปล่อยท่าไม้ตาย
- 5 ดินแดน: ทุ่งหญ้า → ป่า → ถ้ำคริสตัล → ภูเขาไฟ → ปราสาทมืด ชนะ 4 ครั้งเพื่อท้าบอส ปราบบอสเพื่อเปิดดินแดนถัดไป
- เลเวลอัปได้แต้มสถานะไว้แจกเอง วิวัฒนาการที่ Lv 5 (ได้เครื่องประดับตามสี) และ Lv 12 (ได้มงกุฎ)
- ร้านค้าขายยาและอุปกรณ์ (อาวุธ เกราะ เครื่องราง) เซฟอัตโนมัติใน localStorage
- ปุ่มใหญ่อยู่ในระยะนิ้วโป้ง แท็บด้านล่าง รองรับขอบจอมือถือ (safe area) มีเสียงและการสั่นเมื่อโดนตี
