# rb-g-2026

## หิมพานต์ ออนไลน์ (Himmapan Online)

MMORPG แนวพิกเซลบนเว็บ ในป่าหิมพานต์ เขียนเป็นไฟล์เดียว: [`himmapan/index.html`](himmapan/index.html)

- มุมมองแบบ isometric สไตล์ MMORPG 2D คลาสสิก โลกขนาด 96×72 ช่อง สร้างจาก seed เดียวกัน ทุกคนจึงเห็นแผนที่เหมือนกัน
- เมืองตลาดมีวัดทอง น้ำพุกินรี (ยืนใกล้ๆ จะฟื้น HP) แผงลอย พ่อค้าแม่ค้าบนเสื่อ ผู้เฒ่าทองดี (ให้ภารกิจ) และป้าจันทร์ (ขายยาและดาบ)
- ศัตรู 4 ชนิด ยิ่งห่างหมู่บ้านยิ่งเก่ง: วุ้นป่า → เห็ดพิษ → หมูป่าหิน → นาคน้อย
- มีเลเวล XP ทอง ยาสมุนไพร อัปเกรดดาบ 4 ระดับ และภารกิจต่อเนื่อง
- เล่นบนมือถือได้ (จอยสติ๊กและปุ่มบนจอ) และบนคอม (WASD, Space, E, Q, Enter)
- ผู้เล่นหลายคน: เมื่อเปิดเป็น Claude Artifact จะเห็นกันแบบเรียลไทม์และแชทกันได้ ผ่านความสามารถ `room`
  ตัวละครถูกเซฟผ่าน `db` และสำรองไว้ใน localStorage ด้วย

### ข้อจำกัดตอนนี้
- มอนสเตอร์ยังจำลองแยกบนเครื่องของแต่ละคน (ยังไม่มีเซิร์ฟเวอร์กลาง) คนอื่นจึงเห็นกันและแชทกันได้ แต่ยังไม่ได้ตีตัวเดียวกัน
- ขั้นต่อไป: ทำเซิร์ฟเวอร์ Node.js + WebSocket ให้เป็นตัวตัดสิน (authoritative) เรื่องมอนสเตอร์ ดรอปของ และการเซฟ

### ร่างยูนิค (ความลับ ไม่บอกในเกม)
จักรพรรดิปุ๊กปิ๊ก: ได้อัตโนมัติเมื่อปราบมอนลับครบทั้ง 6 ชนิดและ Lv 20 ขึ้นไป ทุกค่า +30% คริ +10% ดูดเลือด ฟื้นเร็ว ของดรอป +30% มีสกิลร่าง “พิพากษาจักรพรรดิ” เปลี่ยนไปร่างอื่นแล้วกลับมาได้ฟรี

### โหมดแอดมิน (สำหรับทดสอบ)
คนที่แก้ไข artifact ได้ (เจ้าของและ editor) จะเห็นปุ่ม 🛠️ แอดมิน ใต้แผนที่ย่อ ใช้เลือกร่างเองได้ทุกร่างรวมร่างลับและร่างยูนิคโดยไม่ต้องสุ่ม ตั้งขั้นร่าง 2–5 เสกมอนลับ แจกของยูนิค ปลดล็อกฉายา/จุดวาร์ปทั้งหมด เปลี่ยนสี เพิ่มเลเวล (ถึง 60) เพิ่มทอง โหมดอมตะ แจกของตำนานครบชุด แจกยา และวาร์ปไปแต่ละดินแดน ผู้เล่นคนอื่นไม่เห็นปุ่มนี้ ตอนเปิดไฟล์บนเครื่องให้ต่อท้าย URL ด้วย `#admin`

### รันบนเครื่อง
เปิดไฟล์ `himmapan/index.html` ในเบราว์เซอร์ได้เลย ถ้าเปิดแบบนี้จะเล่นได้คนเดียว (ออฟไลน์)

## ไข่ปุ๊กปิ๊ก ออนไลน์ (Pukpik Online)

MMORPG ฟักไข่บนเว็บ ทำมาให้เล่นบนมือถือเป็นหลัก เขียนเป็นไฟล์เดียว: [`pukpik/index.html`](pukpik/index.html)

- เข้าเกมมาไข่จะฟักเป็นก้อนกลมๆ สุ่ม 1 ใน 5 สี (โอกาส 5% ได้ตัวประกายแสง) แต่ละสีมีค่าพลังเด่นและสกิลของตัวเอง ค่าเด่นโตเร็ว 2 เท่า

| แดง | ปุ๊กเพลิง | โจมตี (ATK) | ระเบิดเพลิง → หมัดลาวา → คลั่งเพลิง (บัฟโจมตี) → อุกกาบาต |
| น้ำเงิน | ปุ๊กวารี | ป้องกัน (DEF) | โล่วารี → คลื่นซัด → น้ำพุชีวิต (ฮีล) → สึนามิ |
| เหลือง | ปุ๊กสายฟ้า | ความเร็ว (SPD) | สายฟ้าลูกโซ่ → พุ่งสายฟ้า (แดช) → เร่งเครื่อง (บัฟความเร็ว) → พายุฟ้าคำราม |
| น้ำตาล | ปุ๊กผืนดิน | พลังชีวิต (HP) | ดินฟื้นฟู → ทุบพื้น → ผิวหิน (โล่) → แผ่นดินไหว |
| เขียว | ปุ๊กใบไม้ | โชค (LUK) | ใบไม้ดูดพลัง → ดอกไม้บาน → โคลเวอร์นำโชค (บัฟคริ) → พายุใบไม้ |

- เปลี่ยนร่างที่ Lv 20: แต่ละสีมี 5 ร่าง (สายโจมตี ป้องกัน ความเร็ว พลังชีวิต โชค) รวม 25 ร่าง ร่างที่ได้เป็นการสุ่ม แต่ถ่วงน้ำหนักตามค่าสถานะ ค่าไหนสูงกว่าการเติบโตปกติของเลเวลนั้น โอกาสได้ร่างสายนั้นก็ยิ่งมาก (หน้าเปลี่ยนร่างโชว์เปอร์เซ็นต์ก่อนสุ่ม แจกแต้มสถานะเพื่อเพิ่มโอกาสได้) แต่ละสายได้โบนัสค่าพลังและความสามารถติดตัว เช่น สายป้องกันมีโอกาสกันดาเมจได้หมด สายโชคของดรอปบ่อยขึ้น สุ่มร่างใหม่ได้ด้วย 3,000 ทอง

- อุปกรณ์มี 10 ขั้นตามดินแดน บอสจะรวบรวมพลังแล้วทุบพื้นเป็นวงกว้าง (เห็นวงแดงก่อน ให้เดินหลบ)
- ตีมอนแบบเรียลไทม์ ของดรอปลงพื้น เดินทับเพื่อเก็บ อุปกรณ์ 5 ช่อง (อาวุธ เกราะ หมวก รองเท้า เครื่องราง) 5 ระดับความหายาก หมวกและอาวุธที่ใส่จะเห็นบนตัวละคร
- ขายของทีละหลายชิ้น: ในกระเป๋ากด "เลือกขายหลายชิ้น" แล้วแตะเลือกของ หรือใช้ปุ่มเลือกด่วน (ธรรมดาทั้งหมด / ธรรมดา+ดี / แย่กว่าที่ใส่อยู่ / ทั้งหมด) เห็นราคารวมก่อนกดขาย และมีคำเตือนถ้ามีของมหากาพย์หรือตำนานอยู่ในที่เลือก
- เลเวลขึ้นช้าลงตามเลเวล (EXP ที่ต้องใช้ต่อเลเวลที่ Lv 20 ประมาณ 5,300) ตีมอนที่เลเวลต่ำกว่าตัวเองเกิน 3 เลเวลได้ EXP ลดลง 20% ต่อเลเวล (เหลือต่ำสุด 10%) ป้ายเลเวลของมอนเป็นสีเทาเมื่อได้ EXP ลด บอสเกิดใหม่ทุก 150 วินาที
- เลเวลอัปได้แต้มสถานะไว้แจกเอง วิวัฒนาการที่ Lv 5 และ Lv 12
- เล่นได้ทั้งมือถือและคอม (สลับโหมดเองตามอุปกรณ์ที่ใช้ ปุ่ม ❓ ในเกมบอกวิธีเล่นทั้งหมด)
  - มือถือ: ลากนิ้วที่ไหนก็ได้บนจอเพื่อเดิน แตะมอนเพื่อตี แตะพื้นเพื่อเดินไปตรงนั้น กด ⚔️ ค้างเพื่อตีรัว ปุ่มสกิล 4 ปุ่มเรียงรอบ ⚔️
  - คอม: คลิกพื้นเพื่อเดิน (กดค้างแล้วลาก = เดินตามเมาส์) คลิกมอนเพื่อตี (ถ้าไกลจะเดินไปหาแล้วตีต่อ) Shift+คลิก ตีตรงที่ยืน คลิกขวา ใช้สกิลที่ 1, 1-4 ใช้สกิล, K หน้าสกิล, ล้อเมาส์ซูม WASD/ลูกศร เดิน, Space ตี, Tab เล็งมอน, E สกิล, Q/R ยา HP/MP, I กระเป๋า, C ตัวละคร, H วิธีเล่น, Enter แชท, Esc ยกเลิก
- ผู้เล่นหลายคน (ความสามารถ `room` ของ Claude Artifact): เห็นกันแบบเรียลไทม์ แชทกันได้ และตีมอนตัวเดียวกัน หน้าจอของผู้เล่นคนหนึ่งจะเป็นคนขยับมอนให้ทุกคน (ส่งตำแหน่งมอนผ่าน presence) ถ้าคนนั้นออก คนถัดไปจะรับหน้าที่ต่อ ใครตีมอนตัวไหนก็ได้รางวัลและของดรอปของตัวเอง
- เซฟตัวละครและกระเป๋าไว้ใน localStorage ของเบราว์เซอร์ (เซฟเก่าจากเวอร์ชันเทิร์นเบสย้ายมาได้)
